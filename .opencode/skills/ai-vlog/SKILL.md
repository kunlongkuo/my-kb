# AI Vlog 旅遊照片與影片剪輯技能（Agent Skill）

> 本技能源自實測驗證之「AI 自動剪旅遊 Vlog 懶人包」（不用會剪片，只要會講話）。
> 把相簿裡 10～20 個旅遊照片與影片丟入資料夾，設定偏好並用口述方式跟 AI 聊故事，AI 即可自動挑選畫面、排敘事順序、產生帶字預覽圖，經使用者說「OK」後一鍵剪出成片。

---

## 核心價值與設計原則

1. **不用會剪片，只要會講話**：使用者只需將素材丟進資料夾，用日常聊天的口吻語音輸入旅程故事（Win+H 或 Mac 雙擊 Fn），由 AI 負責剪接決策。
2. **直式滿版無黑邊**：預設輸出 9:16（1080×1920, 30fps），照片或橫向影片一律中心裁切滿版，嚴禁上下左右留黑邊或模糊鏡像邊。
3. **優雅細字字幕排版**：
   - 字體細緻（不要加粗、不要黑色描邊、不要突兀色塊底色）。
   - 字高約 72px（約畫面高度 4%），行距為字高的 1.4 倍。
   - 陰影黑色、約 60% 不透明、微模糊，確保可讀性。
   - 字幕置於乾淨畫面背景（天空、牆面、地面），避開雜亂樹葉與人臉。
   - 恪守 IG / FB Reels 安全邊界（上下各留 200px、右側留 120px 按鈕區）。
4. **手機尺寸自檢機制**：預覽圖與成片交給使用者前，AI 必須先縮小為寬 400px（手機尺寸）進行視覺自檢，確保縮小後文字仍清晰可辨。
5. **素材色彩保護**：iPhone 拍攝之 HEIC 靜態照片及 HDR（Dolby Vision / HLG）動態影片，必須在剪輯前完成色彩空間轉換（tonemap 至 BT.709），防止畫面變灰或過曝。
6. **先預覽確認再算片**：AI 先產生各場景「帶字預覽圖（Contact Sheet）」，使用者確認 OK 後才執行最終影片渲染，避免浪費時間與算力。

## 工作流程（4 步驟）

### 步驟 1：素材準備與放置
1. 使用者在工作目錄或桌面的「我的Vlog」資料夾下，新建一個旅程專屬資料夾（例如 `2026_考艾`）。
2. 將 10～20 個旅遊照片與影片放入，不需手動排序或重新命名。
3. 若素材包含不想入鏡的人物（如路人正臉、小孩），可在丟入前挑出，或於設定中指定。

### 步驟 2：偏好設定與故事口述
1. 使用者提供【我的設定】參數（可參考範本或使用預設值）：
   - **素材資料夾**：例如 `2026_考艾`
   - **字體**：自訂 `.ttf` 或使用系統好看的細手寫體 / 黑體
   - **字的大小**：字高約 72 像素（畫面高度約 4%）
   - **字的顏色**：白字 / 米白字 / 黑字（黑色陰影 60% 不透明、稍微模糊）
   - **色調氛圍**：溫暖明亮 / 清新自然 / 復古底片
   - **不要出現在畫面的人**：指定條件或填「無」
   - **發布平台**：IG / FB Reels / 個人留念
   - **目標片長**：預設 30 秒（或 15～60 秒）
2. 使用者以口述或文字分享旅程故事（包含 5 要素）：
   - ① 去哪裡、跟誰
   - ② 最喜歡或最深刻的一刻
   - ③ 整趟氛圍與感受（如：溫暖、慢慢的、熱鬧）
   - ④ 第一個畫面期望放什麼（如：大草地開場）
   - ⑤ 最喜歡的一句話或金句

### 步驟 3：AI 生成場景預覽圖與自檢
1. AI 掃描素材資料夾，辨識照片與影片，執行必要之 HEIC / HDR 色彩轉換。
2. 依故事敘事挑選 6～10 個最佳鏡頭（遠近景交錯、人物與風景搭配、動態影片優先）。
3. 依使用者口述故事精煉每段場景字幕（一句話，短小有感），完成畫面構圖與排版。
4. 產生各場景「有字預覽圖」，並將總覽圖拼成 Contact Sheet。
5. 縮小至 400px 寬度自檢字幕清晰度。確認合格後呈現給使用者確認。

### 步驟 4：確認輸出與成片
1. 使用者檢視預覽圖，回覆「OK」（若要調整，依「修改規則」指出）。
2. AI 調用 FFmpeg 或內建腳本進行剪輯，串接轉場、字幕、滿版裁切。
3. 若使用者需要音樂，可加入指定或無版權輕快背景音樂（淡入淡出）。
4. 影片輸出於素材資料夾中的 `我的Vlog.mp4`，剪輯完成回報使用者。

## 剪輯 9 大核心規則

| 編號 | 規則名稱 | 具體執行要求 |
| :--- | :--- | :--- |
| **01** | **畫面挑選** | 挑最好看、最能說故事的畫面，排除模糊與重複。遠景、近景、人物、風景保持多樣性，動態影片優先保留。 |
| **02** | **敘事對齊** | 嚴格按照使用者講述的故事脈絡推進，講到什麼地點/情節，對應放該場景的鏡頭。 |
| **03** | **標準規格** | 直式 9:16、解析度 1080×1920、影格率 30fps，影片總長度嚴格符合目標設定（預設 30 秒）。 |
| **04** | **中心滿版裁切** | 每個畫面必須滿版，嚴禁出現黑邊或兩側模糊鏡像條；非 9:16 素材從幾何中心向外裁切。 |
| **05** | **優雅細字排版** | 每一段場景一句短字幕；字體細緻不加粗、不描邊、不加色塊底；行距為字高 1.4 倍；放置於乾淨背景（天空/牆面/地面），避開人臉與雜亂物件；避開 Reels 上下 200px、右側 120px 操作遮蔽區。 |
| **06** | **手機尺寸自檢** | 預覽圖與成片輸出前，縮小至寬 400 像素自檢，縮小後文字仍清晰易讀方可通過。 |
| **07** | **色彩轉檔防灰** | iPhone HEIC 照片轉換為 sRGB JPG；HDR / Dolby Vision 影片強制使用 `zscale`/`tonemap` 轉換至 BT.709，確保色彩不變灰、不泛白。 |
| **08** | **人物過濾** | 設定中指定「不要出現在畫面的人」，凡有符合特徵之畫面一律剃除不用。 |
| **09** | **中文友善交互** | 全程以繁體中文與使用者溝通；成片儲存於素材資料夾之 `我的Vlog.mp4`。 |

---

## 不滿意修改規則

當使用者對預覽圖或初版影片提出修改時：
1. 引導使用者一次講完所有欲調整處（例如：「第 2 鏡換成吃冰淇淋的照片、第 4 鏡的字改成『陽光剛好』」）。
2. 遵循「其他都不要動」原則，僅精確重做指定鏡頭之裁切或文字，保留其餘已確認之片段。
3. 重新產生受影響鏡頭之預覽圖或直接重新拼接成片。

## 輔助腳本庫

本技能附帶以下實用 Python 腳本（位於 `<skill>/scripts/`）：
- `check_env.py`：檢查電腦是否已安裝 FFmpeg、中文字體與必要 Python 函式庫。
- `heic_hdr_converter.py`：自動將素材中 HEIC 轉成 JPG，以及將 HDR 影片透過 FFmpeg tonemap 轉換為 BT.709 SDR。
- `vlog_builder.py`：根據分鏡與字幕設定檔，自動完成滿版裁切、文字繪製、預覽圖產生與 FFmpeg 成片輸出。
