# Querying and answers

## 查詢流程

1. 接收問題，辨識主題與關鍵詞。
2. 選擇最相關的索引或來源檔；可先用 `source-map.md` 決定閱讀順序。
3. 取得候選 chunk，依內容、標題、摘要及相關性排序。
4. 以能直接回答問題的原文內容組成答案，並附來源檔名及可取得的 chunk 編號。

## 隨附腳本查詢

```bash
python <skill-dir>/scripts/skill_rag.py query --index <index.json> --question "<question>" --top-k 5
```

腳本依關鍵詞 token 重疊計分，並對標題和 chunk 標題加權；它不是 embedding 或語意搜尋。命中分數只適合排序候選，不應被描述為可信度或語意相似度。

## 命中與低信心處理

- 單一候選明顯較相關時，優先使用該候選。
- 多筆候選接近時，選能直接回答問題的內容，必要時交叉比對。
- 候選不相關、內容不足或知識庫未收錄時，不要硬答；說明缺口，請使用者補充關鍵詞或提供候選文件。
- 資料庫／索引只存摘要或 chunk 不完整時，回到原始來源查核（前提是可讀取）。
- 多來源有衝突時，指出衝突及來源；只有資料明確支持時間先後時，才以較新的內容為準。

## 建議回答格式

**答案：** 直接回答及必要說明。

**來源：** `source_name` / chunk 編號（若可取得）。

需要時補充限制、摘要或仍待確認的資訊。不要只靠記憶回答，不要省略可取得的來源資訊，也不要把未命中的內容拼湊成結論。
