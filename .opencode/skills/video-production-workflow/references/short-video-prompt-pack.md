# 短影音提示詞總包

這是短影音工作的單一入口，適合直接複製後開始使用。

## 快速版

```text
請幫我處理這支短影音需求：

- 內容主題：
- 影片類型：教學型 / 活動紀錄型 / 社群科普型 / 個人日誌型
- 目標平台：
- 預計長度：
- 受眾：
- 想強調的重點：
- 不想出現的元素：
- 可接受的風格：
- 是否允許 `B-roll` / 動畫 / 音樂 / `CTA`：

先判斷內容類型，選 preset，給我 4 到 8 句可執行的剪輯策略。
```

## 規劃版

- 想先分類再剪輯時，使用 [短影音提示詞模板](short-video-prompt-template.md)。
- 想看具體案例時，使用 [短影音實戰範例](short-video-examples.md)。
- 想快速查流程時，使用 [短影音速查表](short-video-cheatsheet.md)。

## 執行版

- 想一次規劃加執行時，使用 [完整工作指令模板](full-agent-instruction-template.md)。

## 建議流程

1. 先貼上快速版並填空。
2. 讓 `video-production-workflow` 先分類需求並選 preset。
3. 若需要實作，再交給 `video-autopilot`。
4. 想一次完成，就改用完整工作指令模板。
