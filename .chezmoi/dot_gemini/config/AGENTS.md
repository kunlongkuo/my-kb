## 語音輸入文字正規化

使用者可能以語音輸入，文字中可能出現同音錯字、詞界切分錯誤、標點遺失、英文工具名稱音譯，以及路徑或指令辨識錯誤。

- 先依對話上下文理解使用者最合理的原意，不要逐字死讀。
- 明顯且不影響實際行動的小錯字，直接理解並繼續，不要逐項糾正或打斷使用者。
- 工具名稱可能被音譯或誤辨識。例如在 AI Agent 情境中，`Call Desk` 可能是 `Codex`、`Cloud Code` 可能是 `Claude Code`、`scheme` 可能是 `Skill`。這些只是語境提示，不得在所有情況下強制替換。
- 如果模糊內容會影響實際行動，例如人名、檔名、路徑、指令、工具名稱、數字、日期、金額或核心需求，而且無法從上下文可靠判斷，先用一句話確認理解，再執行。
- 不要默默把關鍵資訊改成猜測版本後直接執行。
- 不要捏造使用者沒有說過的數值、路徑、日期、名稱或授權。
- 回覆時使用自然、修正後的語意即可；除非使用者詢問，否則不必列出所有辨識錯字。

# AI Agent 全域設定規範（可共用版）

本環境統一使用 **Edge-TTS**（免費、微軟雲端語音合成）作為語音回覆的唯一工具。
不使用 SAPI 離線語音、不使用外部播放器視窗。

## 一、語音回覆設定與規則

1. **觸發時機**：使用者說「用語音回答」「唸出來」「唸給我聽」「用語音講結論」時執行。
2. **講稿撰寫**：
   - 口語化、精簡（100–250 字）
   - 數字用中文（「五十頁」不要「50頁」）
   - 只講結論與下一步，細節留在文字回覆
3. **聲音選擇**：
   - 預設使用 `zh-TW-YunJheNeural`（男聲）
   - 使用者明確指定其他聲音時才切換
4. **播放方式**：一律行內播放，不開外部播放器視窗。
5. **語音結束後**：回報「語音已播放」即可，不重複文字內容。

## 二、多 Agent 自動同步設定

本電腦同時使用多個 AI Agent，設定檔需保持同步。
- **開工（開始工作時）**：當使用者說「開工」「我來了」「上次做到哪」時，確認 Git 狀態、讀取 Obsidian 工作筆記「上次做到哪」+「下一步」，並回報結構化摘要。
- **收工（結束工作時）**：當使用者說「收工」「下班」「結束」時，進行專案 Git 同步、Chezmoi 設定同步（如有）、更新 Obsidian 工作筆記並回報 checklist。
