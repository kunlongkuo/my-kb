# 黑糖麻糬蛋塔（16 個）

## 📋 主材料

| 材料名稱 | 份量 |
| ----- | ----- |
| **酥皮** | 10 片 |
| **全蛋** | 2 個 |
| **動物性鮮奶油** | 110 克 |
| **牛奶** | 170 克 |
| **黑糖** | 50 克 |
| **麻糬** | 適量 |

## 👩‍🍳 製作步驟

### 1. 塔皮處理

1. 將酥皮攤開，第一片捲起（剛開始中心需捲實）。
2. 第二片疊在第一片尾部稍微按壓，一起捲起來。
3. 依序重複相同步驟，捲至第五片，完成一根圓柱狀。
4. 切成 8 等分切塊後，壓成圓形塔皮。
5. 另外 5 片依照上述相同步驟捲成第二根圓柱狀，同樣等切成 8 塊並壓成圓形塔皮（共 16 個塔皮）。

### 2. 塔液製作

1. 將黑糖與牛奶放入鍋中加熱煮勻。
2. 同時將鮮奶油與 2 顆全蛋攪拌均勻。
3. 將煮勻的黑糖牛奶沖入鮮奶油全蛋液中，充分攪拌均勻。
4. 將混合好的蛋塔液過篩備用。

### 3. 填裝

1. 在 16 個塔皮杯內放入適量麻糬。
2. 將過篩後的蛋塔液平均倒入 16 個麻糬塔皮杯中。

### 4. 烤焙設定與時間

* **烤箱預熱／設定**：上下火 $210^\circ\text{C} / 210^\circ\text{C}$
* **烘烤時間與步驟**：
  * 先以 $210^\circ\text{C}$ 烤 10 分鐘。
  * 將烤盤轉動 $180^\circ$，維持烘烤溫度 $210^\circ\text{C}$ 再烤 10 分鐘。
  * *（總烘烤時間約 20–25 分鐘，視表面著色與上色均勻度調整）*
