# 焦糖布丁食譜筆記 (12杯)

## 份量與準備

* **成品數量**：12 杯
* **烹調方式**：隔水蒸烤

## 一、 原料清單

### 1. 焦糖

| 原料 | 重量/數量 | 備註標記 |
| ----- | ----- | ----- |
| 砂糖 | 100 克 | ① |
| 水 | 20 克 | ② |
| 熱水 | 20 克 | ③ |

### 2. 簡易焦糖 (備用 5克)

| 原料 | 份量 |
| ----- | ----- |
| 黑糖 | 1 匙 |
| 水 | 5 匙 |
| 布丁粉 | 1 匙 |

### 3. 布丁液

| 原料 | 重量/數量 | 備註標記 |
| ----- | ----- | ----- |
| 砂糖 | 120 克 | ① |
| 牛奶 | 650 克 | ② |
| 動物性鮮奶油 | 120 克 | ③ |
| 雞蛋 | 5 個 | ④ |
| 香草莢 | 半支 | ⑤ |

## 二、 製作步驟

### A. 焦糖層製作

1. 將 **① 砂糖 (100g)** + **② 水 (20g)** 倒入小鍋中，開中小火加熱。過程請勿攪拌，只需輕輕晃動鍋子讓糖均勻受熱。糖液會先沸騰起大泡泡，接著慢慢轉成金黃色、再變成深琥珀色。
2. 看到冒出微煙且散發焦糖香時立刻關火。
3. 小心倒入 **③ 熱水 (20g)**（注意：此時會產生大量高溫蒸氣，請小心不要被燙傷），快速晃動鍋子讓焦糖與水融合。
4. 將焦糖液趁熱平均倒入 12 個布丁模具底部，靜置放涼至凝固變硬。

### B. 布丁液製作與分裝

1. 將 **① 砂糖 (120g)** + **② 牛奶 (650g)** + **⑤ 香草莢 (半支剖開刮出籽及莢（可去除蛋腥味）)** 倒入鍋中，加熱至 $60^\circ\text{C} \sim 70^\circ\text{C}$ 溫熱即可，不需要煮滾。
2. 在大碗中將 **③ 鮮奶油 (120g)** + **④ 雞蛋 (5個)** 混合拌勻（不要打入太多空氣，避免產生氣泡）。
3. 將步驟 1 溫熱的牛奶液分次、緩慢倒入步驟 2 的蛋液中拌勻。
4. 將調好的布丁液過篩 2 次，濾掉沒打散的蛋白與去除氣泡雜質，這樣蒸烤出來的口感才會滑順細緻，倒入量杯中。
5. 拿取量杯，將布丁液平均分裝入已裝有焦糖底的 12 個布丁杯內。

### 焦糖避免發苦的注意事項

1. **留意顏色與火候**：焦糖化約在 $160^\circ\text{C} \sim 180^\circ\text{C}$ 的範圍進行；糖液到深琥珀色、散發焦糖香時就應準備離火。若繼續加熱到黑褐色或冒出刺鼻焦味，糖已過度焦化，成品會有明顯苦味。此處是焦糖化，不是梅納反應。
2. **看到合適顏色就立刻離火**：焦糖顏色變化很快，別只依賴計時；鍋具和糖漿的餘溫仍會繼續加深顏色。微微冒煙、聞到焦糖香時立即關火，不要等到糖色變黑。
3. **迅速加入熱水停止加熱**：關火後小心加入配方中的熱水（20 克），並快速晃鍋使其融合。會冒出大量高溫蒸氣，請避免燙傷；不要拖延，以免餘溫讓焦糖繼續變苦。熱水用量依配方，不要任意多加。

## 三、 烘烤與冷藏條件

* **烤箱溫度**：上火 $150^\circ\text{C}$ / 下火 $150^\circ\text{C}$
* **烘烤時間**：40 ~ 50 分鐘
* **烤法**：隔水蒸烤（烤盤注入熱水高約 1~2 公分）
* **冷藏與保存**：出爐後放涼，蓋上蓋子或保鮮膜，放入冰箱冷藏冰鎮 3 到 4 小時以上，口感更紮實美味。
