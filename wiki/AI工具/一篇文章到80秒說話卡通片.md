# 一篇文章到80秒說話卡通片 — AI 自動化短影音 Pipeline

整合 ChatGPT/Claude、Pollinations.ai (Flux)、MiniMax、HyperFrames 與 Replicate Lyria 2，建構低成本（單支約 NT$18）、高效率（熟練後 5-10 分鐘）的自動化短影音生成流水線。

## 4 大 AI 廚師接力

### 1. 剪劇本（Claude / ChatGPT）
- 精簡長文為 **23 句字幕**（80 秒、平均每句 3.5 秒、不超過 20 字）
- 黃金故事線：**Hook → 緣起 → 卡點 → 領悟 → 教訓 → CTA**

### 2. 畫場景（Pollinations.ai / Flux）
- 生成 **7 張背景插圖**，每張對應一個故事段落
- 關鍵字：`Morandi 配色`、`Flat Illustration`、`Q-version Cartoon`、`Paper grain texture`
- 固定 seed 鎖定角色一致性

### 3. 克隆人聲（MiniMax）
- 錄製 60-90 秒乾淨音檔上傳克隆專屬語音 ID
- **黃金設定**：`speech-02-hd`、`speed: 1.1`、`emotion: calm`
- **重要**：繁體中文先以 `opencc` 轉簡體送 TTS（避免破音），字幕維持繁體

### 4. 拼貼渲染與配樂（HyperFrames + ffmpeg + Replicate）
- **HyperFrames**：GSAP 時間軸控制 HTML/CSS，渲染輸出為 MP4
- **Replicate Lyria 2**：生成 110 BPM 商用安全背景音樂（30 秒，crossfade 拼接至 90 秒）
- **ffmpeg**：Python 腳本自動計算 23 句字幕毫秒時間戳，精準混音

## 7 大痛點避坑指南

| 痛點 | 解決方案 |
|------|----------|
| 音頻漏字 | Gemini 轉錄用 60-90 秒小 chunk 分段 |
| 配音有陸腔 | 繁轉簡送 TTS，emotion 切 `calm` |
| 角色不一致 | Prompt 加 character lock + 固定 seed |
| 字幕遮擋 | 字幕設 `bottom: 100px` + 半透明漸層 |
| 首秒黑畫面 | 首張圖 GSAP fade-in duration 設為 `0` |
| 數字符號發音怪 | 數字轉漢字（`2026` → `二零二六`） |
| 結尾硬切突兀 | ffmpeg 音軌最後 2 秒加 `afade=t=out` |

## 兩條實作路線

- **路線 A（無代碼初學者）**：ChatGPT + Pollinations + InVideo/CapCut 手動拼貼
- **路線 B（自動化進階者）**：Node.js + Python + ffmpeg + API，`voice_pipeline_full.py` 一行命令自動完成
