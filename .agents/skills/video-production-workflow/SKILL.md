# 短影音剪輯工作流

這個技能用來先分流、再規劃，最後才進入實作。

## 如何使用

1. 先判斷影片是教學型、活動紀錄型、社群科普型，還是個人日誌型。
2. 再確認平台、長度、受眾、風格與限制。
3. **分流決策**：根據素材特性選擇執行路徑（見下方「執行路徑分流」）。
4. 如果資訊不夠，先問一個最必要的問題。
5. 先產出剪輯策略，再進入實作。

## 執行路徑分流

根據素材類型，選擇最適合的執行 Skill：

### 路徑 A-E → `video-autopilot`（CapCut / JSON / ffmpeg）

適用情境：
- 有大量視覺效果、動態字幕、貼圖、轉場特效需求
- 素材以 B-roll、畫面剪接為主（非口播講話）
- 需要精細的 CapCut 模板控制
- 音樂剪輯、節奏卡點類影片

路徑對照：
- 路徑 A：只輸出
- 路徑 B：字幕或模板加輸出
- 路徑 C：更深度的樣式處理加輸出
- 路徑 D：JSON 直接編輯後再輸出
- 路徑 E：純 ffmpeg

### 路徑 F → `video-use-editor`（AI 對話式精剪，逐字稿驅動）

適用情境：
- 素材以「口播、講話、訪談、教學說明」為主
- 需要自動剪掉 uh/um/贅詞/死空間/重複跑
- 有多 take 素材需要智慧選取最佳 take
- 希望 Agent 讀完逐字稿後主動提出剪接建議
- 說話類影片需要精確字幕（word-level 對齊）

路徑 F 工具：ElevenLabs Scribe 逐字稿 + ffmpeg render

> 不確定走哪條路？問使用者：「這支影片的主要素材是講話/口播，還是以畫面剪接為主？」

## 使用原則

- 先分類，再設計。
- 策略要能直接執行，不要只停留在抽象概念。
- `B-roll`、動畫、音樂、`CTA` 都是 opt-in，不是預設。
- 如果需求模糊，先問一個最關鍵的問題，不要硬套模板。

## 工作流程

1. 判斷影片類型與發布目標。
2. 選擇執行路徑（A-E 或 F）。
3. 用 `Hook / Setup / Peak / Turn / Echo` 檢查敘事是否完整。
4. 定義字幕、節奏、畫面與聲音限制。
5. 先輸出 4 到 8 句白話剪輯策略，再進入實作。
6. 預覽後做 QA，確認畫面、字幕、節奏與音訊都達標。

## 內容類型

- 教學型：講清楚一件事，優先保證理解與節奏。
- 活動紀錄型：保留現場感與關鍵瞬間，優先情緒與時間線。
- 社群科普型：先給結論或反差，再補證據與解釋。
- 個人日誌型：重視情緒、口吻與臨場感，不必過度資訊密集。

## 輸出要求

- 先說明你判定的內容類型。
- 再說明建議長度、平台與字幕風格。
- **明確指出建議走路徑 A-E（video-autopilot）還是路徑 F（video-use-editor）**，並說明理由。
- 如果要進一步開剪，必須先給出明確的策略摘要。
- 如果現有 preset 不夠用，先提出自訂方案，不要勉強套用。
