# 短影音實戰範例

這些範例可當成實際可用的短影音提問樣板。

## 1. 教學型

```text
請幫我處理這支短影音需求：

- 內容主題：如何用三個步驟整理會議筆記
- 影片類型：教學型
- 目標平台：YouTube Shorts
- 預計長度：60 秒
- 受眾：上班族、知識工作者
- 想強調的重點：快速、實用、看完能直接照做
- 不想出現的元素：過多動畫、空泛口號
- 可接受的風格：簡潔、乾淨、資訊密度中等
- 是否允許 `B-roll` / 動畫 / 音樂 / `CTA`：可接受少量 `B-roll`，不要強音樂

請先判斷內容類型，選 preset，然後給我一版可執行的剪輯策略。
```

## 2. 活動紀錄型

```text
請幫我處理這支短影音需求：

- 內容主題：公司年度聚會精華
- 影片類型：活動紀錄型
- 目標平台：Instagram Reels
- 預計長度：45 到 75 秒
- 受眾：同事、客戶、合作夥伴
- 想強調的重點：現場氣氛、關鍵瞬間、團隊感
- 不想出現的元素：過度旁白、像廣告片
- 可接受的風格：真實、流暢、有節奏感
- 是否允許 `B-roll` / 動畫 / 音樂 / `CTA`：可用音樂，但不要搶現場聲

請先判斷敘事重點，再提一版 `Hook / Setup / Peak / Turn / Echo` 的策略。
```

## 3. 社群科普型

```text
請幫我處理這支短影音需求：

- 內容主題：為什麼很多人學了一堆工具還是沒效率
- 影片類型：社群科普型
- 目標平台：Threads + YouTube Shorts
- 預計長度：30 到 45 秒
- 受眾：想提升工作效率的上班族
- 想強調的重點：先給結論，再補原因
- 不想出現的元素：長篇鋪陳、太多術語
- 可接受的風格：直接、有反差、字幕清楚
- 是否允許 `B-roll` / 動畫 / 音樂 / `CTA`：可以少量動效，但以訊息優先

請先幫我判斷最適合的敘事結構，並列出字幕與節奏限制。
```

## 4. 個人日誌型

```text
請幫我處理這支短影音需求：

- 內容主題：第一次一個人旅行的心得
- 影片類型：個人日誌型
- 目標平台：TikTok
- 預計長度：60 到 90 秒
- 受眾：喜歡旅遊與生活感內容的人
- 想強調的重點：情緒、臨場感、觀眾代入感
- 不想出現的元素：過度包裝、像廣告文案
- 可接受的風格：溫柔、自然、留白多
- 是否允許 `B-roll` / 動畫 / 音樂 / `CTA`：可用氛圍音樂，避免太滿

請先幫我選 preset，再給我一版適合這種口吻的剪輯策略。
```
