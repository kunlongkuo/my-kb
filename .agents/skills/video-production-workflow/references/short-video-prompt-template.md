# 短影音提示詞模板

當你希望 agent 先分類短影音需求、再進入剪輯時使用。

可先參考 [短影音實戰範例](short-video-examples.md) 看具體案例。

```text
請幫我處理這支短影音需求：

- 內容主題：
- 影片類型：教學型 / 活動紀錄型 / 社群科普型 / 個人日誌型
- 目標平台：
- 預計長度：
- 受眾：
- 想強調的重點：
- 不想出現的元素：
- 可接受的風格：
- 是否允許 `B-roll` / 動畫 / 音樂 / `CTA`：

請先：
1. 判斷最適合的內容類型
2. 選一個對應 preset，或提出自訂 preset
3. 用 `Hook / Setup / Peak / Turn / Echo` 簡述剪輯策略
4. 列出字幕、節奏、畫面與聲音的限制
5. 只在確認後再進入實作
```

## 補充

- 如果是教學內容，補上「希望觀眾看完後學會什麼」。
- 如果是活動紀錄，補上「最重要的現場瞬間」。
- 如果是社群科普，補上「最想先抓住的反差或結論」。
- 如果是個人日誌，補上「想保留的情緒與口吻」。
