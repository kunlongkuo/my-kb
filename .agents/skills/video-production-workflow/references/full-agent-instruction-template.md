# 完整工作指令模板

當你要一次把規劃與執行都交給 agent 時使用。

```text
請幫我處理這支短影音工作：

【內容資訊】
- 主題：
- 影片類型：教學型 / 活動紀錄型 / 社群科普型 / 個人日誌型
- 目標平台：
- 預計長度：
- 受眾：
- 必須保留的內容：
- 必須避開的內容：
- 允許的風格：

【製作限制】
- 是否允許 `B-roll`：
- 是否允許動畫：
- 是否允許音樂：
- 是否允許 `CTA`：
- 是否可以重新排列原始順序：
- 是否可以加入字幕強調：

【工作要求】
1. 先用 `video-production-workflow` 判斷最適合的內容類型與 preset
2. 如果資訊不足，只問一個最必要的問題
3. 用 `Hook / Setup / Peak / Turn / Echo` 提出可執行的剪輯策略
4. 說明字幕、節奏、畫面與聲音的限制
5. 若需要執行 `CapCut` / `ffmpeg` / export，再交給 `video-autopilot`
6. 先策略，後製作，不要直接跳到剪輯

【交付格式】
- 先給分類結果
- 再給剪輯策略
- 再給 QA 檢查重點
- 最後列出下一步
```

## 建議使用時機

- 想要 agent 一次完成規劃與執行時使用。
- 只想先規劃、還沒要動手剪時，改用較短的模板。
- 想看具體案例時，先參考範例檔。
