# 蝦皮短影音文案與配套貼文模板庫

> 核心邏輯：AI 快速產出「口播腳本」＋「同版社群貼文」，一人作業高效率，人工僅需核對商品資訊與語氣。

---

## 1. 蝦皮帶貨短影音黃金節奏（15–45 秒）

短影音觀眾注意力短暫，前 3 秒決定跳出率，後續展示決定下單率：

| 階段 | 時間長度 | 目標 | 視覺重點 | 口播重點 |
| :--- | :--- | :--- | :--- | :--- |
| **Hook（黃金鉤子）** | 0 – 3s | 抓眼球、引出常見痛點或驚艷效果 | 商品特寫或衝突情境（如：「又壞了？」「桌面一團亂」） | 一句話命中痛點、反問或驚嘆句 |
| **Demonstration（實測示範）** | 3 – 12s | 展示真實使用過程與第一視角操作 | 實際按壓、開箱、擺設、即時功能展現 | 說明使用時的直觀感受、有多方便 |
| **Core Value（核心亮點）** | 12 – 25s | 交代 1~2 個最硬核的規格或賣點 | 產品細節微距鏡頭、質感呈現 | 條理分明、避免術語堆疊，講人話 |
| **CTA（行動呼籲）** | 25 – 35s | 引導至黃色購物袋 / 留言領券 / 首頁連結 | 標示指向左下角購物車或分潤商品 | 提醒促銷優惠、折扣券、點擊連結下單 |

## 2. 四大常見帶貨腳本模板

### 模板 A：痛點解決型（最容易引發共鳴）
- **適用商品**：收納用品、清潔工具、桌面整頓、小家電、隨身小物
- **腳本結構**：
  - 【0-3s Hook】：「你是不是也常常覺得 [某件煩心事] 很抓狂？」
  - 【3-12s 實測示範】：「自從用了這個 [商品簡稱]，只要 [簡單動作]，立刻搞定！」（畫面帶實拍操作）
  - 【12-25s 核心亮點】：「它最棒的地方是 [賣點 1]，而且 [賣點 2]，材質很厚實。」
  - 【25-30s CTA】：「左下角黃色購物車現在有現貨，點進去看看吧！」

### 模板 B：高顏值好物開箱型（視覺衝擊、衝動消費）
- **適用商品**：美妝保養、3C 配件、手錶飾品、文具、居家擺設（如番茄鐘、Pocket 4P 配件）
- **腳本結構**：
  - 【0-3s Hook】：「實品比想像中更有質感！今天開箱這個超紅的 [商品名稱]。」
  - 【3-12s 實測示範】：「手感超級順，你看這個 [材質/按鍵反饋/螢幕顯示]，細節做得很到位。」
  - 【12-25s 核心亮點】：「體積小巧不佔空間，隨身攜帶或放在桌上都超吸睛。」
  - 【25-30s CTA】：「趁現在蝦皮免運活動，連結在左下角，手慢就被搶光啦！」

### 模板 C：實測對比型（理智型消費者殺手）
- **適用商品**：充電線/快充頭、防水防污用品、運動裝備、廚房用具
- **腳本結構**：
  - 【0-3s Hook】：「普通款跟升級款到底差在哪？今天直接測給你看！」
  - 【3-15s 實測示範】：「左邊是傳統的，右邊是這款 [商品名稱]。你看，速度直接快了一倍，而且完全不發燙。」
  - 【15-25s 核心亮點】：「經過官方認證，安全有保障，價格竟然才幾百塊。」
  - 【25-30s CTA】：「性價比真的沒話說，喜歡的朋友點左下角下單。」

### 模板 D：限時促銷 / 高 CP 值撿便宜型
- **適用商品**：耗材類、零食包、生活日常補貨
- **腳本結構**：
  - 【0-3s Hook】：「等等！如果你正想買 [商品]，先看這部省荷包！」
  - 【3-12s 實測示範】：「這組在蝦皮真的賣爆，一整包拿在手上份量十足。」
  - 【12-20s 核心亮點】：「日常消耗品就是要選這種大碗滿意、品質過關的。」
  - 【20-28s CTA】：「領券下單現折，庫存有限，趕快把握！」

## 3. 同版配套社群貼文文案規格（配套輸出）

每產出一支短影音腳本，同步生成一份同版文字貼文，供蝦皮短影音說明欄、IG Reels 或 Facebook 導購使用：

```markdown
【標題】：🔥 實測有感！[商品亮點/吸睛痛點一句話]
【內文說明】：
大家常常問我的 [商品名稱] 終於整理好實測心得啦！
自用了一段時間，最喜歡的 3 個重點：
1. 💡 [亮點 1]：實際體驗一句話。
2. 💡 [亮點 2]：規格或材質細節。
3. 💡 [亮點 3]：解決日常什麼困擾。

【下單方式】：
👉 點擊左下角黃色購物袋直接選購
👉 搭配賣場優惠券＋蝦皮免運最划算！

#蝦皮開箱 #好物推薦 #實測評測 #[商品類別] #蝦皮短影音
```

## 4. 人工審閱重點（文案語氣 Check）
1. **去書面化**：將「此產品具備優良之效能」改成「這顆真的很好用，充超快」。
2. **去除虛假絕對詞**：避免「最頂級、全台第一、百分之百療效」等違規廣告字眼。
3. **核對真實規格**：確認文案中的尺寸、容量、充電瓦數與拍到的商品實物一致。
