# 影片字幕與動態視覺特效指令庫（20 Video Subtitle & Motion Effects）

本技能整理自短影音與 AI 影片剪輯實戰（源自 IamLily「20 個影片特效指令：複製貼給 Claude 就能做」），透過 Python、ffmpeg、rembg（人像分割去背）與 faster-whisper（語音時間對齊），讓 AI 以逐影格（frame-by-frame）程式運算方式，為 9:16 直式口播影片精準疊加動態字幕、物理碰撞、圖層前後穿插、遮罩與視覺特效。

---

## 核心價值與使用原則

1. **拒絕死板模板，堅持精準客製**：剪映模板無法自由調整字體在人物後方、難以隨語音音節觸發；本技能提供 20 段經過實戰驗證的程式化特效指令，位置、顏色、速度、字型與時間皆可完全掌控。
2. **三道機械防護閘門**：
   - **定格預檢閘門**：輸出完整影片前，必須先生成 3 張定格圖確認排版與圖層順序，使用者確認「OK」後才進行全片段算圖。
   - **語音對齊閘門**：以口播片段中的「念到關鍵字的那一格」為時間觸發點，先轉逐字稿取時間戳，不要等念完才出現。
   - **圖層遮罩契約**：需要「字在人後」（★★★ 難度）的特效，嚴格遵守圖層階級 `底圖 → 特效層 → 去背人像 → 前景層`，避免圖層穿幫。
3. **剪映獨立特效層輸出模式（降級相容）**：若不希望 AI 直接覆蓋原影片，可指示輸出「透明底 ProRes 4444 .mov」或「黑底 mp4（以剪映畫中畫＋濾色模式疊加）」。

## 標準執行架構與共用指令環境

執行這 20 個特效時，必須在指令與執行環境中遵循以下底層共用規範：

```text
【基本要求】
1. 程式棧：使用 Python (Pillow, OpenCV, numpy) 與 ffmpeg 逐影格合成。
2. 畫面規格：輸出 1080x1920（9:16 直式），影格率（FPS）與音訊軌道嚴格繼承原影片，不掉格、音畫同步。
3. 字型管理：預設從 GitHub google/fonts 下載開源字型（繁體中文優先使用 Noto Sans TC / Noto Serif TC / Mochiy Pop One / LXGW WenKai TC）。若本機缺字或下載失敗，立即回報並請求使用者提供字型檔。
4. 定格確認：處理完整影片前，強制產出 3 張具代表性的時間點定格圖（含開始、高潮、結尾狀態）。待確認回覆「OK」後才算完全片。
5. 語音對齊：若需配合說話出現，使用 faster-whisper（或 ffmpeg 音波振幅包絡）定位目標字詞的精確起點影格（On-beat），務必於念到的那一格瞬間觸發。
6. 去背分層：難度 ★★★ 特效強制使用 rembg（u2net_human_seg 模型）或 mediapipe 人像分割。產出 Alpha 通道遮罩，確保「人壓在字前」邊緣乾淨無黑邊毛邊。
```

## 20 個特效完整提示詞與調優庫

### 01 動態文字 (Kinetic Motion Text)
- **難度**：★★★
- **準備素材**：直式口播影片（1~3秒）、2 個英文字（例如：`motion`、`text`）
- **完整提示詞**：
```Plain Text
我上傳了一段直式口播影片，請幫我加「動態文字」特效，直接交回加好特效的成品影片。

第一行字：【motion】
第二行字：【text】

基本要求：用 Python 和 ffmpeg 一格一格處理；輸出 1080x1920，影格率和聲音照原片；字型從 GitHub 的 google/fonts 下載，下載失敗就停下來請我上傳字型檔；先給我 3 張定格圖確認位置，我說 OK 再輸出影片。
去背：用 pip 安裝 rembg，用人像模型 u2net_human_seg 把每一格的人去背；裝不起來就改用 mediapipe 的人像分割；兩個都不行就停下來告訴我卡在哪。

特效做法：
1. 字型用 Montserrat 的 ExtraBold Italic（粗斜體）。白字、細黑邊。兩行字上下疊成一塊。
2. 畫面中下方，同一塊字縮得很小（約最大時的 11%），由下往上排成 8 層，層和層之間約 90 像素。
3. 每層每秒往上走一格，越往上越大；走到畫面上方約 30% 高度時「突然」放大到寬度撐滿畫面，再繼續放大並淡出。最大的那幾層改成半透明的灰白色（約 35% 不透明），像背景裡的大字；小字保持白色。
4. 最下面持續補上新的小字，做成無縫循環，從片段開頭到結尾都在動。
5. 疊的順序：底圖 → 循環文字 → 去背的人。人壓在字的前面，字經過頭和身體時會被人擋住。整塊字放在頭的高度附近，讓字從頭後面穿過去。
```
- **做不好時這樣問（調優提示詞）**：
  - *字太多、太亂*：「排隊的層數改成 5 層，間距加大到 120 像素」
  - *字跑到人的前面*：「檢查疊的順序：字要在去背的人後面，給我一張去背結果的黑白圖確認」
  - *想換中文字*：「字型改成 Noto Sans TC 最粗的字重，字改成【你的中文字】」

### 02 標題字卡 (Title Card)
- **難度**：★★
- **準備素材**：直式口播影片、標題文字、念到標題的關鍵字/時機
- **完整提示詞**：
```Plain Text
我上傳了一段直式口播影片，請幫我加「標題字卡」特效，直接交回加好特效的成品影片。

標題：【標題字卡】
開始打字的時機：我念到【標題】的時候

基本要求：用 Python 和 ffmpeg 一格一格處理；輸出 1080x1920，影格率和聲音照原片；字型從 GitHub 的 google/fonts 下載，下載失敗就停下來請我上傳字型檔；先給我 3 張定格圖確認位置，我說 OK 再輸出影片。
對時間：我會告訴你「念到哪個字」時出現效果。先把我的口播轉成帶時間的逐字稿（例如用 pip 安裝 faster-whisper），找到那個字在第幾秒；裝不起來就用 ffmpeg 量音量變化來估，並在定格圖上標出秒數讓我確認。效果要在我念到那個字的那一格出現，不要念完才出現。

特效做法：
1. 片段一開始，整個畫面換成米白色紙（RGB 242,238,230）。
2. 左上方一行小小的時間碼（格式像 00:00:02:15），字型用 Roboto Mono，深灰色，字高約畫面寬 3%，跟著影片時間一直跳。
3. 標題用 Noto Serif TC 粗字重（約 700），深灰色，一行兩個字、靠左排，每個字高約畫面寬 20%，放在時間碼下方。念到標題時逐字打出，每個字約 0.08 秒。
4. 原片放進一個圓形裡：直徑約畫面寬 40%，以臉為中心裁切，放在標題的右下方（可以稍微疊到標題最後一個字），圓外一圈淡淡的柔和陰影。圓形從開頭就在。
5. 全部停到片段結束。
```
- **做不好時這樣問（調優提示詞）**：
  - *標題太晚出現*：「標題第一個字改成在【0.2】秒出現」
  - *圓裡的臉太小*：「圓裡的畫面放大 1.5 倍，以臉為中心裁切」
  - *想要深色版*：「紙張改成深灰色，標題改白字」

- **完整提示詞**：

```Plain Text
我上傳了一段直式口播影片，請幫我加「打字機」特效，直接交回加好特效的成品影片。

三行字：【IamLily 2.0】【with】【Claude】
開始打字的時機：我念到【IamLily】的時候

特效做法：
1. 字型用 Inter Tight Bold，三行同大小、置中，字高約畫面寬的 10%，白字加深色柔和陰影。英文以外的字改用 Noto Sans TC 粗體。
2. 0.1～0.3 秒：在第一行上方畫一條橘色（#FF6B35）粗線，厚約 26 像素，從畫面中間往左右拉開到兩邊各留 44 像素。
3. 接著三行字逐字打出，每個字約 0.04 秒，第一行打完接第二行。整塊字放在胸口的高度，不能蓋到臉。
4. 打完停約 0.4 秒，之後整塊字（含橘線）在剩下的時間慢慢往上升，到片段結束時第一行頂端到畫面上方約 130 像素的位置。
```
- **做不好時這樣問（調優提示詞）**：
  - *字蓋到臉*：「整塊字往下移到胸口以下」
  - *打字太快*：「每個字改成 0.07 秒」
  - *想換顏色*：「橘線改成【你的色碼】」

- **完整提示詞**：


```Plain Text
3. 約 0.2 秒起，從圓形外框往外擴散 2～3 圈細細的橘色圓環（約 4 像素），一圈接一圈，邊擴散邊變淡。
4. 片段最後約 0.4 秒：圓形放大到蓋滿整個畫面（先慢後快），標題和紙同時被推出畫面，回到正常的全畫面影片。
```
- **做不好時這樣問（調優提示詞）**：
  - *圓裡的臉太小*：「圓裡的畫面放大 1.4 倍，以臉為中心」
  - *放大太快*：「最後放大到全畫面的時間改成 0.6 秒」
  - *圓環不明顯*：「圓環改成 6 像素粗，慢一點變淡」

## 剪映（CapCut）工作流整合指引

如果你習慣使用剪映剪接長片，只想把 Claude 作為**特效資產生成器**，請在以上任一段提示詞最後追加以下指令：

```text
這次不要動我的影片，只輸出特效那一層：透明背景的 .mov（ProRes 4444）；如果做不出透明的，就給純黑底 mp4。尺寸（1080x1920）和長度跟我的片段完全一樣。
```

### 剪映中合成技巧：
1. **透明 .mov（ProRes 4444）**：
   - 在剪映中，將原口播置於主軌道，新增「畫中畫」（PIP）置入生成的 .mov。
   - 對齊時間軸起始點即可完美覆蓋。
2. **純黑底 mp4**：
   - 若系統或環境無法產出 ProRes 4444，使用黑底 mp4 疊在畫中畫軌道。
   - 選取該畫中畫片段，至右側檢查器將「混合模式」（Blend Mode）切換為**「濾色」（Screen）**，所有純黑底色即刻透明化。
3. **分層限制提醒**：
   - ★★★「字在人後面」的立體穿透效果需要雙圖層遮罩。若使用剪映，必須在剪映中複製一份口播軌道並以智慧去背放在最上層，將特效層夾在中間；或者直接交給 AI 一鍵合成完整影片。

## 拍攝前策劃與 AI 來回修改 4 大心法

1. **先企劃，再錄影**：
   - 特效是在錄影前就規劃好的。例如要壓扁字（13），錄影時雙手就要做合攏手勢；要點擊圖示（14），手指就要指對高度與方位。
   - **錄影時人不要離鏡頭太近**：給畫面頭頂、左右邊界保留 20%~30% 構圖留白，才有充裕空間擺放字卡與特效。
2. **逐字稿腳本為準**：
   - 將原口播腳本文字一併提供，要求字幕嚴格依腳本生成，避免語音辨識誤判同音字。
3. **一次只改一件事（單變數迭代）**：
   - 不要一次丟出 5 項修改要求；每次專注於「位置調整」、「字型替換」或「時間微調」，維持代碼穩定性。
4. **版本編號與風格記憶**：
   - 每次產出要求明確標註 `v1`、`v2`、`v3`，以便隨時回滾。
   - 確定滿意的色彩（如活力橘 `#FF6B35`、暖白紙 `#F2EEE6`）與字型後，要求 Claude 記錄為全片專案設計規範（Tokens）。
