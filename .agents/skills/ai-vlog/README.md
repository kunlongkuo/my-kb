# AI Vlog 旅遊照片與影片剪輯技能

旅遊照片丟進去，用講的，AI 幫你剪成直式 9:16 高質感旅遊 Vlog！
本技能專為 AI Agent 設計，支援從相簿原始素材（照片、動態影片、HEIC、HDR）一鍵全自動處理至成片輸出。

---

## 快速上手

### 1. 建立旅程素材資料夾
在專案或桌面建立資料夾，例如 `2026_考艾`，丟入 10～20 個旅遊照片與影片。

### 2. 複製設定與口述故事
複製以下設定並分享你的旅程：

```markdown
【我的設定】
・素材資料夾：（2026_考艾）
・字體：（沒有，用好看的細手寫字體）
・字的大小：（字高約 72 像素，大約是畫面高度的 4%）
・字的顏色：（白字／米白字／黑字），陰影要明顯：黑色、約 60% 不透明、稍微模糊
・色調：（溫暖明亮／清新自然／復古底片），每個畫面顏色要一致，不要太飽和
・不要出現在畫面的人：（例如：小孩、路人正臉／沒有就寫「無」）
・要發在哪裡：（IG、FB Reels／只是自己留念）
・長度：（30 秒）

故事分享（用講的）：
「這次和家人說走就走去考艾，餵羊的時候大家都笑了。整趟就像回到清境農場一樣慢慢走，溫暖又放鬆。第一個畫面放大草地，字寫『慢慢走、慢慢看，就是最美好的回憶』。」
```

### 3. 看預覽圖說「OK」
AI 會產生每個場景帶有文字的預覽圖（Contact Sheet），縮小自檢後呈現給您。確認無誤說「OK」，即可全自動算片完成。
