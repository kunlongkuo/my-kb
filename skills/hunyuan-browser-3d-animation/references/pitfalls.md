# 下載、拓樸與本案例界線

## 網頁操作與下載

- Browser Use 操作生成頁；先讀當前工具文件。工具表面、分頁、選單和版本會改變，案例索引／座標不能當腳本常數。
- 下載成功提示、匯出對話框消失或播放畫面存在，都不是取得本機檔案的證明。記錄接收路徑並核對格式、大小和匯入結果。不要把 HTML 登入頁存成 `.glb`／`.fbx` 後列為成功。
- 下載事件等待曾出現遠超指定 timeout 的卡住。若發生同類問題，不再重複掛同一等待；先檢查瀏覽器下載清單、目前頁面與本機落地檔，再考慮不同有依據的路徑。
- 對頁面已公開並已載入的同一份模型，若本次工具規則與使用者授權允許，可用檔案傳輸工具取回當前觀測到的資產。這只算檔案下載，不能記成呼叫生成 API。不可猜私有 API、抽取 Cookie／Token、保存授權網址，或繞過網站權限。
- 更換瀏覽器可能需要重新登入，不能假定兩個瀏覽器共享會話。需要使用者本人操作時說明精確阻礙，避免讓使用者重新做已完成的生成。
- 同原因已連續失敗兩次時，不再原樣重試。保存任務狀態，採有證據的替代方式或回報可用階段與具體阻礙。

## 減面與衣物

- 原始 GLB 常因 UV／法線分割而包含重合頂點。直接大幅減面可能出現臉部斑點；單純關掉法線貼圖未必有效。
- 以尺度合適的容差焊接重合頂點、重新計算法線，再減面。焊接不能跨越原本分離的手指、嘴部、衣層或配件。
- 輪廓已乾淨但 UV 接縫或袖口邊條破碎時，將高模原始底色烘焙到新工作網格 UV，再逐角度檢查。烘焙底色不能補回不存在的背面參考，也不代表保留原 PBR 全套材質。
- 自動綁骨對長袍、寬袖、帽帶常需人工調權重。骨架名稱齊全不代表衣物變形合格；測試完整動作，而不只單張截圖。
- Blender 節點名稱受介面語言影響；用節點 `type` 選取 Principled BSDF／Material Output 等，不只依賴英文顯示名稱。Blender 4.5 動作切換驗證需確認對應 action slot。

## 交付狀態與報告

靜態 GLB 的 skin／animation 數量可以合法為零；要交付角色動畫時，需有實際使用的蒙皮、骨架動作與播放驗收。檢查工具只證明結構，不能判斷衣袍是否穿模或動作自然。

報告用 HTML 顯示比較與耗時表格，原稿 Markdown 可作下載附件。保留目前任務狀態，不硬寫固定 localhost 連接埠或依賴另一專案正在運作的服務。動畫版本可播放；靜態版本標明並停用動作按鈕。
