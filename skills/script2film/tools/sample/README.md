# 拆片量測（tools/sample）

拆外部樣本時，把樣本和自己的片用**同一把尺**量，數字才比得起來。工具只量、不下判斷。

```
python3 tools/sample/breakdown.py <樣本.mp4> [--vs <我方片.mp4> ...] --out <資料夾> [--every 3]
```

全部在本機跑、不花錢（逐字稿用 whisper.cpp）。影片旁邊不會多任何檔，產出都在 `--out`：

| 檔 | 內容 |
|---|---|
| `measure.md` | 並排表：第一欄樣本，其後是 `--vs` 的片 |
| `measure.json` | 每支片一筆，欄位見 `breakdown.measure` |
| `words_<名>.json` | 逐字稿與每個字的開始時間（中文已轉繁體） |
| `sheet_<名>_NN.jpg` | 聯絡表：每 N 秒一格，格下寫開始時間與這幾秒說的字；6×5 一張 |

## 每項怎麼量

| 項目 | 量法 | 出處 |
|---|---|---|
| 換畫面點 | ffmpeg scene > 0.15、去掉下方 22% 字幕帶 | `tools/nightly/pace.py` `scene_cuts`（成片檢查同一支） |
| 鏡頭數與長度 | 相隔 ≤ 0.3 秒的連續換點併成一次再算；另記沒合併的 `raw_cuts` | 快轉、快速移動在 0.15 下每格都觸發 |
| 前 30 秒最長不換畫面 | 沒合併的換點；片長不到 30 秒寫空 | `pace.first30_gap`（FORMAT §4c／§4e） |
| 整體響度、最安靜 5% | ebur128；16 kHz 每 0.1 秒 RMS 的第 5 百分位 | `tools/nightly/film_check.py` |
| 說話 | 只數漢字；說話時間＝相鄰兩字開始時間差 ≤ 門檻的加總；門檻報 0.35、0.5、0.65 秒 | `doc_common.local_asr` |

## 已知限制

- **字卡的「動」被低估**：只算整個畫面換掉；程式畫面裡逐條出現的字卡、照片推近不一定過 0.15。拿我方解說片比換鏡數時記得這點。
- **語速依賴停頓門檻**：同一組片，門檻 0.3 秒時差一成，0.65 秒時幾乎一樣；說話時間佔比的高低順序則每個門檻都一樣。所以表格三個門檻都列，別只看一欄下結論。
- **說話量測只支援中文**。非中文的片 `speech` 是空的。
- 沒設 `S2F_WHISPER_CPP_MODEL`：說話量測不做，其他照量，`measure.md` 第一行說怎麼設。

## 量完怎麼用

工具不判斷。另寫一份拆解文件，三段：
1. **觀察**：樣本做了什麼，指得出 `measure.md` 的哪一列、聯絡表的哪一格。
2. **反證**：對照自己的規範（先搜既有規則，寫出搜了哪些關鍵字），樣本推翻、支持、還是不相干。量法會影響結論的，換門檻再看一次。
3. **落地**：要改的規則或檢查，附依據；沒有要改的就寫沒有。
