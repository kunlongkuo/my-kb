# Contributing

Bug reports, fixes and documentation improvements are welcome.

## Setting up

Follow [docs/INSTALL.md](./docs/INSTALL.md). For working on the code you need at least steps 2 to 6 (the Python
packages, Playwright's headless browser, `npm ci`, the HyperFrames headless browser and the two fonts); the voice models
of step 7 are only needed to make a film.
`python3 tools/doctor/doctor.py` tells you what is missing.

## Running the tests

```bash
.venv/bin/python -m pytest -q        # or: python3 -m pytest -q, when the packages are in your own Python
```

This runs the tests under `skills/` and `tools/` (several hundred, about a minute). `tools/score` is a separate
project with its own tests: `cd tools/score && uv run python -m pytest -q`.

- The scene tests need the two fonts in `assets/fonts/` and the packages from `npm ci`. Without them those tests fail;
  they do not skip.
- Some tests skip when an optional part is missing. `pytest -rs` prints why: the YouTube packages
  (`google_auth_oauthlib`) are not installed, `S2F_TEST_FONT` is not set (point it at a `.ttf` file), or
  `PALETTE_SRC_ROOTS` is not set (palette source files that are not shipped). A skip is fine; a failure is not.
- Many scene tests also need Playwright's own headless browser (step 3: `.venv/bin/python -m playwright install
  --only-shell chromium`). Without it they fail with "Executable doesn't exist".
- CI (`.github/workflows/ci.yml`, on pushes to main and on pull requests) does steps 2 to 6 of `docs/INSTALL.md` on a
  fresh Apple Silicon macOS runner, then `python3 tools/doctor/doctor.py --skip voice` and
  these tests. It does not install the voice and transcription models and does not make a film, so run
  `examples/coffee` yourself when you change the voice, timing or cutting steps.

## Rules for some files

- **Website.** The Chinese pages in `docs/` are the source. `docs/en/` is generated by `python3 tools/site/build_en.py`
  from the pairs in that script; do not edit `docs/en/` by hand. The same command writes the share-preview tags
  (Open Graph, canonical, hreflang) into all eight pages from the site address in `tools/site/site_config.py`; run
  `python3 -m pytest -q tools/site` afterwards. `python3 tools/site/make_og.py` remakes the preview image
  `docs/site/og.jpg`, only when it should change.
- **Prompt Studio.** After changing `tools/prompt-studio/prompt-studio.html`, run `python3 tools/site/sync_studio.py`
  to update the website copy (`docs/studio/app.html`). A test fails when the two differ.
- **Storyboard rules.** `skills/ve-director/references/` is generated from `skills/ve-director/rules/`. After editing a
  rule, run `python3 skills/ve-director/scripts/build_refs.py` and commit both.
- **Skills.** After adding or renaming a skill under `skills/`, run `python3 tools/agents/sync.py`.
- **Settings.** A script that reads an `S2F_*` setting starts with the four config lines
  (`tools/config/tests/test_config.py` checks this).

## Before you open a pull request

- The tests pass.
- No keys, tokens, account names, personal paths or private material. Keys belong in
  `~/.config/script2film/secrets.json` or the environment, never in the repository.
- Every asset you add (sound, image, font, music) has a licence that allows redistribution, with a source you can cite,
  and is recorded in [NOTICE.md](./NOTICE.md) (sounds also in `assets/sfx/manifest.json`).

## What the tools must keep doing

These come from [AGENTS.md](./AGENTS.md) and [docs/FLOW.md](./docs/FLOW.md). A change should not weaken them.

- Using a real person's voice needs that person's consent. Otherwise use a designed voice that belongs to nobody.
- No real person's photo goes to a video model. A host's likeness is the user's own, or one the user has the right to
  use.
- Ask the user before spending their generation credits (VideoExpress, TalkingPhotos). Upload, publish, schedule or
  delete a video only when the user says so. Tell the user before sending audio to cloud transcription.
- The user logs in to web platforms; the tools never type account names or passwords.
- No news-agency or broadcaster photos or footage. Every asset in a film has its source and licence recorded.
- Every Concat export goes through `tools/concat/concat_export.py`, which checks the film
  (`tools/nightly/film_check.py`); `tools/concat/test_single_export.py` fails if a script writes its own export loop.
  A film that fails the check (or `tools/nightly/check.py` for explainers) is not delivered. `--no-check <item>:<reason>`
  and the checklist's `--skip-checklist` are used only with the user's agreement, and both are logged.
