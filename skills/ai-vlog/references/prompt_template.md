# 提示詞範本（Prompt Template）

當使用者要剪輯 Vlog 時，可複製以下整段提示詞並填寫【我的設定】，接續用口述分享故事：

```markdown
【我的設定】（只改括號裡的字，有好幾個選項的留下一個）
・素材資料夾：（2026_考艾）
・字體：（資料夾裡的字體檔「＿＿.ttf」／沒有，用好看的細手寫字體）
・字的大小：（字高約 72 像素，大約是畫面高度的 4%）
・字的顏色：（白字／米白字／黑字），陰影要明顯：黑色、約 60% 不透明、稍微模糊
・色調：（溫暖明亮／清新自然／復古底片），每個畫面顏色要一致，不要太飽和
・不要出現在畫面的人：（例如：小孩、路人正臉／沒有就寫「無」）
・要發在哪裡：（IG、FB Reels／只是自己留念）
・長度：（30 秒）

等一下我會用講的，跟你說這趟旅程的故事。聽完後，請直接做好每一段場景一張有字的預覽圖，一次全部給我看。我說 OK，你就剪成影片，中間不用再問我。

剪的規則：
1. 挑最好看、最能說這個故事的畫面，模糊的、重複的不要，不用全部用完。遠景、近景、人、風景要有變化，有影片的話多用會動的畫面。
2. 照我講的故事排順序，講到什麼就放什麼的畫面。
3. 直式 9:16、1080×1920、30fps，長度照設定。
4. 每個畫面都要滿版，不能有黑邊或重複拼接的條；比例不合的，從中間裁切到滿版。
5. 畫面上的字從我講的話裡寫，每一段場景一句，要短、有感覺。字體、大小、顏色、陰影照設定。字要細，不要加粗、不要描邊、不要黑框或底色；行距是字高的 1.4 倍。字放在乾淨的地方（天空、牆面、地面），不要放在樹葉這種很花的背景上，不要壓到臉。要發在 IG、FB Reels 的話，字不要太貼最上面、最下面和右邊。
6. 預覽圖和成片交給我之前，先把畫面縮小成手機大小（寬 400 像素）自己看一次，縮小後字還看得清楚才算合格。
7. 有 HEIC 照片或 HDR 影片先轉檔，顏色不要變灰。
8. 設定裡「不要出現在畫面的人」，有出現的畫面一律不用。
9. 請用中文回覆。
剪好的影片存成「我的Vlog.mp4」，放在素材資料夾。
```

## 配樂要求補充語句（選用）

若需要 AI 協助混音加入配樂，可在對話末尾追加：
- 「請幫我加入一首輕鬆溫馨的吉他輕音樂，音量適中，結尾淡出。」
- 「影片預設不帶音樂，我想在發布到 IG / Reels 時於後台挑選當紅音訊。」
